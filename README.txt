# PROFESSIONAL PORTFOLIO WEBSITE
### Agrima Sareen | B.Tech Computer Science and Engineering (Data Science)

## 1. Project Overview

This repository contains the source files for a personal professional portfolio website developed to present academic background, technical skills, selected projects, and professional contact information.

The portfolio is designed as a single-page, responsive website with an editorial visual style, structured navigation, and dedicated sections for presenting relevant information and work.

## 2. Website Sections

The website is organized into five primary sections:

- **About:** Introduction, academic background, and areas of interest.
- **Projects:** Selected academic, collaborative, and personal projects, including their objectives, technologies, and contributions.
- **Skills:** Overview of technical skills and programming technologies.
- **Resume:** Access to the downloadable PDF resume.
- **Contact:** Professional contact information and relevant external links.

## 3. Technologies Used

- HTML5 — Website structure and content.
- CSS3 — Layout, responsive styling, typography, and visual design.
- JavaScript — Interactive elements and navigation behaviour.

The website uses a responsive layout to support viewing across desktop and mobile devices.

## 4. Repository Structure

```text
agrima-portfolio/
│
├── index.html
├── Agrima_Sareen_Resume.pdf
└── README.txt
```

- `index.html` contains the complete portfolio website.
- `Agrima_Sareen_Resume.pdf` contains the downloadable resume linked from the website.
- `README.txt` provides project documentation.

The HTML file and resume PDF are maintained in the same directory to ensure that the resume link functions correctly.
