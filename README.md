## Overview

This repository hosts the source code for the personal professional portfolio of **Agrima Sareen**, developed to showcase academic background, technical capabilities, selected projects, and professional interests.

Designed as a responsive, single-page website, the portfolio combines an editorial visual style with structured navigation to provide an accessible overview of academic and technical work.

## Website Sections

The portfolio is organized into five primary sections:

- **About:** Introduction, academic background, and areas of interest.
- **Projects:** Selected academic, collaborative, and personal projects, highlighting their objectives, technologies, and contributions.
- **Skills:** Overview of technical competencies, programming languages, and development technologies.
- **Resume:** Access to the downloadable PDF resume.
- **Contact:** Professional contact information and relevant external links.

## Technologies Used

| Technology | Application |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Layout, responsive styling, typography, and visual design |
| JavaScript | Interactive elements and navigation functionality |

The website is designed to provide a consistent browsing experience across desktop and mobile devices.

## Repository Structure

```text
agrima-portfolio/
│
├── index.html
├── Agrima_Sareen_Resume.pdf
└── README.md
```

- `index.html` — Contains the portfolio website.
- `Agrima_Sareen_Resume.pdf` — Downloadable copy of the professional resume.
- `README.md` — Project documentation.

The website and resume are maintained in the repository's root directory to ensure that the resume download link resolves correctly.

## Deployment

The portfolio is hosted using **GitHub Pages**, with deployment configured directly from the repository.

| Configuration | Setting |
|---|---|
| Hosting Platform | GitHub Pages |
| Publishing Source | Deploy from a branch |
| Branch | `main` |
| Directory | `/ (root)` |
